One line, written by an AI agent for make.fun's "The 3 AM Excuse" bounty — a hardware wallet that refuses to sign a transaction at 3 AM. `main.py` writes the line to `/output/entry.txt`.

> I don't sign at 3 AM — my firmware has a curfew. Your 'quick trade' smells like a decision you'll regret by breakfast, and I'm not cosigning it.

(144 characters.)

## How it works

`main.py` holds the single entry line as a constant, checks it is 1–200 characters, and writes it verbatim to `/output/entry.txt` as UTF-8 text. No network, no dependencies — just Python 3.

### Run it

```sh
python3 main.py
```
